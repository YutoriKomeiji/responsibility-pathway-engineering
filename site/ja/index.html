AIの「提案」と「実行してよい」を分ける。

RPEは、AIエージェントや自動化システムが外部操作へ進む前に、要件、承認、証拠、次の責任担当を確認するための責任評価レイヤーです。既存の実行基盤を置き換えず、その前段に判断ポイントを追加できます。

English 日本語 README サポート
現在利用できる範囲: Python評価API、ローカル/呼び出し元データのローダー、REST/MCPリファレンスアダプター、スキーマ、CI付きのデモを、記載された範囲で試せます。RPE自身は外部操作の実行、本番向け認証・認可、法令適合の自動判定を提供しません。
