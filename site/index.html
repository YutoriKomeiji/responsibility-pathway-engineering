Open Source / Active Development

Keep AI proposals separate from permission to act.

RPE adds an inspectable responsibility check before an AI agent or automation continues to an external action. It evaluates requirements, approval and evidence conditions, and the next responsibility owner without becoming the executor.

English 日本語 README Support
Current use: The public Python evaluation path, local/caller-content loader, REST/MCP reference adapters, schemas, and CI-backed examples can be tried within their documented boundaries. RPE does not provide external execution, production identity controls, or automated legal/compliance authority.
